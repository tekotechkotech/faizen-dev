# Point 19 — Scope & Non-Goals

## Project Scope

> **Faizen Company Profile + Faizen CMS**

## Included

- Public company website
- Build
- Solution
- Service
- Article
- Hero
- Media
- Inquiry/contact
- Company Settings
- Analytics/measurement
- Error/empty states
- Technical requirements defined in this PRD
- Custom CMS

## Explicit Non-Goals

The project does not include:
- Pure SPA
- Headless CMS
- Filament
- Microservices
- Kubernetes or complex infrastructure
- Generic CMS product
- Full API/platform ecosystem

## Scope Rule

> Anything not explicitly defined in this PRD is not part of the scope.

If a requirement is unclear, it must be discussed and explicitly decided before being added.

Future possibilities must not be treated as current requirements without an explicit decision.
