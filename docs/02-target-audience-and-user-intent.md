# Point 02 — Target Audience & User Intent

## Principle

> Faizen’s website is intent-driven, not persona-driven.

## Priority Audiences

1. **Potential Customers / Partners** — people with needs, problems, or ideas requiring digital solutions.
2. **Existing-Product Users** — people looking for a Faizen product, SaaS, or API.
3. **Strategic Partners** — developers, agencies, companies, investors, or collaborators.

Investors are secondary unless fundraising becomes active.

## UX Direction

Visitors must not be forced to select a persona. Navigation should let users proceed based on what they want to accomplish.

The primary distinction is:
- Find an existing solution.
- Build a new solution together.
- Explore partnership opportunities.
