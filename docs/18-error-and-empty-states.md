# Point 18 — Error & Empty States

## Error Page Requirements

Error pages must:
- Show the error page and error code.
- Keep the navbar.
- Keep the footer.
- Present a clear error message.
- Use UI consistent with Faizen.
- Avoid exposing sensitive technical information.

## Relevant Error States

- 404
- 403
- 419
- 429
- 500

## Example

```
Navbar

404
Page Not Found

[Back to Home]

Footer
```

## Empty States

Empty states must remain within the Faizen visual system and explain the context. They must not become unexplained blank pages.
