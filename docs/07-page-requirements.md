# Point 07 — Page Requirements

## Overall Structure

- HOME
- BUILD
  - Build Detail
- SOLUTIONS
  - Solution Detail
- WITH US
- ARTICLES
  - Article Detail
- SERVICES
  - Service Detail
- LET’S BUILD TOGETHER

## Page Purposes

- **Home** — understand, attract, and direct.
- **Build** — provide proof.
- **Solutions** — provide usable products.
- **With Us** — explain who Faizen is and how to work together.
- **Articles** — knowledge, SEO, and discovery.
- **Services** — explain what can be built together.
- **Let’s Build Together** — conversion endpoint.

## Build Detail

Sections:
- Project Hero
- Context/problem
- Solution
- Key features
- Screenshots/visuals
- Result/impact
- Optional technology
- CTA

Technology must not lead the narrative.

## Solution Detail

Sections:
- Product Hero
- Problem
- What it does
- Features
- Screenshots/demo
- Pricing
- FAQ
- CTA / Get Started

If the product has an independent brand:

> A product by Faizen

## With Us

Sections:
- Who we are
- What we believe
- How we work together
- What we can build
- Partnership
- Founder/company
- Let’s build together

## Articles

- Listing
- Detail
- Categories
- Related Solutions/Builds

## Services

Examples defined for the initial service structure:
- Custom Software
- System Development
- API Integration
- Maintenance

## Let’s Build Together

Form intent:
- Existing solution
- Custom solution
- Partnership
- Other

Fields:
- Name
- Email/WhatsApp
- Brief description

One conversion endpoint with low friction.
