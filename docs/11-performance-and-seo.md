# Point 11 — Performance & SEO

## Principle

> Performance & SEO are first-class requirements, not post-development optimization.

## Performance Requirements

- Fast HTML delivery
- JavaScript only where needed
- WebP/AVIF where appropriate
- Responsive images
- Lazy loading outside the viewport
- Explicit image dimensions
- Font optimization
- Minimized CSS/JS
- High priority for hero assets
- Core Web Vitals target: **Good**

## SEO Requirements

- Title
- Meta description
- Canonical
- Open Graph metadata
- Twitter/X Card metadata
- sitemap.xml
- robots.txt
- Semantic HTML
- Structured data where relevant

## URL Structure

Clean URLs such as:

- `/build/sistem-ppdb-smk`
- `/solutions/whatsapp-api`
- `/services/custom-software`
- `/articles/cara-membangun-sistem-ppdb`

SEO is not limited to articles. The complete content ecosystem contributes to discovery.
