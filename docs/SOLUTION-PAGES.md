# Solution Listing and Detail Pages

## Overview

This document defines the Solution pages structure, translating the brand statement **BUILD · SOLUTIONS · WITH US** into product-oriented pages focused on usability and conversion. The SOLUTIONS area answers the visitor intent *"Can I get this?"* — do I want an existing solution?

---

## Solution Listing

### Purpose
Display all of Faizen's available products and solutions that people can use. This is the primary entry point for visitors browsing existing solutions.

### Layout Structure

1. **Hero section** — "What we offer" or category introduction; typographic-first approach
2. **Solution grid/cards** — List of solutions with title, brief description, and visual preview
3. **Filter/organization** — By product type or use case (if applicable)
4. **CTA** — "Let's build together" for custom inquiries or "View solution" to detail page

### Anti-Slop Compliance
- **Color Palette**: Neutral zinc/slate/stone base; emerald accent for CTA highlights only
- **Typography**: Max 2 fonts (Display: Geist Display/Cabinet Grotesk; Body: Plus Jakarta Sans/Satoshi); no italic headers
- **Information Density**: High density — solution cards grouped tightly; no empty spacing that reduces density
- **No bento grids**: Use structured section rhythm; solutions presented in purposeful layout
- **No floating rounded icon boxes**: Solution cards contain title/description visuals only
- **Product-first**: Solutions displayed before company information
- **Product identity**: When applicable, show "A product by Faizen" branding

### Sections Planning
- Listing page highlights the most relevant/usable solutions
- Each solution card teases what it does without overwhelming detail
- Primary CTA prominent but de-emphasized relative to the product showcase
