# Define visual direction

## Goal

Establish the visual design direction consistent with Faizen Studio, Digital Solutions, partnership-first positioning, and Do More, Less Explain.

## PRD Reference

- `docs/prd/03-brand-and-ux-principles.md`

## Dependency

- TASK-002

## Area / Files

Visual design system

## Implementation

- [ ] Define visual hierarchy
- [ ] Define spacing principles
- [ ] Define typography direction
- [ ] Define imagery direction
- [ ] Define interaction tone
- [ ] Check alignment with brand statements

## Acceptance Criteria

- [ ] Direction reinforces Product First, Company Second
- [ ] Direction supports one primary understanding per screen
- [ ] Direction does not rely on generic software-house visuals

## Definition of Done

- [ ] Direction is documented
- [ ] Design decisions are traceable to brand principles

## Technical Notes

Exact font, palette, and visual assets remain decisions within this task rather than assumed defaults.
