# Select analytics provider

## Goal

Choose the analytics provider needed to implement the approved event contract without assuming a provider.

## PRD Reference

- `docs/prd/15-analytics-measurement-and-product-intelligence.md`

## Dependency

- TASK-008

## Area / Files

Analytics provider decision

## Implementation

- [ ] Evaluate providers against privacy, event support, performance, and deployment constraints
- [ ] Select one provider
- [ ] Record the decision

## Acceptance Criteria

- [ ] One provider is explicitly selected
- [ ] Decision supports the approved event contract
- [ ] No sensitive unnecessary data is required

## Definition of Done

- [ ] Decision is documented
- [ ] Implementation task can proceed

## Technical Notes

Decision task only; implementation is separate.
