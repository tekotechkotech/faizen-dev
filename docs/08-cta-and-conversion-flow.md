# Point 08 — CTA & Conversion Flow

## Principle

> One website, multiple paths, one clear next action.

## CTA by Intent

- Existing solution → **Get started / Try it**
- Custom solution → **Let’s build together**
- Partnership → **Start a conversation**
- Build detail → **Let’s build together**
- Solution → **Get started**
- Article → related Solution/Build CTA

Visitors must not be forced into a form when a more direct action is appropriate.

## Conversion Loop

> **Discover → Understand → Trust → Act**

## Example Paths

### Search/Discovery

Google → Article → Solution → Get Started

### Referral

Referral → Home → Build → Project Detail → Let’s build together

### Direct

Home → Solutions → Product → Get Started
