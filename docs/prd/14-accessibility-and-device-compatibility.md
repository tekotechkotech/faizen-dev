# Point 14 — Accessibility & Device Compatibility

## Principle

> Mobile-first, not mobile-adapted.

The first market priority is the device that is easiest for visitors to reach.

## Device Priority

> **MOBILE → TABLET → DESKTOP**

## Mobile Requirements

- Hero must remain strong on mobile.
- CTA must be easy to reach.
- Navigation must remain simple.
- Important content comes first.
- No desktop-first assumptions.
- Images/video must be optimized for mobile connections.
- Touch interaction must be considered.
- Mobile performance is a priority.
- Desktop is an enhancement of the mobile experience.

## Browser Support

- Chrome
- Edge
- Firefox
- Safari

## Accessibility

- Semantic HTML
- Keyboard navigation
- Visible focus states
- Adequate contrast
- Alt text
- Correct handling of decorative images
- Labeled forms
- Understandable form errors
- Information must not rely on color alone
- No-mouse interaction support
- Reduced-motion consideration

## Progressive Enhancement

Content remains accessible without JavaScript where possible. JavaScript enhances interaction rather than becoming a prerequisite for basic content.

## Principle

> Accessible by default, responsive by design, enhanced by JavaScript.
