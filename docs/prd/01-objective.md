# Point 01 — Objective

## Purpose

Faizen Studio website exists to create meaningful partnerships by offering existing digital solutions and providing a path to build new solutions together.

## Objectives

1. **Partnership** — build meaningful, long-term partnerships.
2. **Existing Solutions** — help visitors discover and use solutions already built by Faizen.
3. **Custom Solutions** — give visitors a clear path to bring a problem or idea and build a solution together.

## Core Logic

- **“Can I get this?”** → Products / existing solutions.
- **“Can you build this with me?”** → Custom solutions.

## Scope Rule

Anything not explicitly defined in this PRD is not part of scope. Unclear requirements must be discussed and explicitly decided before being added.
