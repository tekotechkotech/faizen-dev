# Point 05 — Landing Page

## Purpose

The landing page must quickly communicate what Faizen builds, what visitors can use, and how to proceed.

The page should be compact, professional, and action-oriented.

## Structure

1. Navbar
2. Hero
3. What We Build
4. Final CTA
5. Footer

## Hero

Use a two-column layout:

- Left: positioning/copy and CTA.
- Right: selected project/product carousel.

The exact hero copy is not yet locked.

### Hero Carousel

The carousel is not an advertising banner. It is a portfolio/product teaser.

Requirements:
- Maximum 3–4 strongest items.
- Screenshot/image.
- Title/context.
- Optional **View Case Study**.
- Demonstrates what Faizen actually builds rather than relying on abstract illustration.

## What We Build

Use one visual ecosystem with clear type labels:

- **BUILD / CLIENT PROJECT**
- **SOLUTION / FAIZEN PRODUCT**
- **SERVICE**

The visual language should be unified while allowing each type to expose its relevant information.

## Final CTA

> **Let’s build together.**

## Avoid

Do not add generic sections such as:
- “Why choose us”
- Fake statistics
- Fake testimonials
- Fake years of experience
- Generic jargon
- Generic process sections
- Technology-stack showcases

These are not required by this PRD.
