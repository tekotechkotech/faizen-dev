# Point 16 — Testing & Quality Assurance

## Principle

> Nothing is done until it works, performs, and remains usable across its intended environment.

## Functional Testing

Test all implemented functionality, including:
- Navigation
- Build
- Solution
- Service
- Article
- Hero
- CMS
- Contact/inquiry
- CTA

## Responsive Testing

Testing starts with mobile and covers:
- Layout
- Interaction
- Navigation
- Readability
- Touch targets
- Images

Then verify tablet and desktop behavior.

## Performance Testing

Verify:
- Core Web Vitals
- Page load
- Image loading
- JavaScript impact
- Mobile network behavior

Priority pages:
- Home
- Build
- Solution
- Article

## SEO Testing

Verify:
- Crawlability
- Metadata
- Canonical URLs
- Sitemap
- Open Graph
- Heading structure
- Broken links

## Accessibility Testing

Verify:
- Keyboard navigation
- Focus states
- Contrast
- Semantic HTML
- Alt text
- Forms
- Reduced motion

## Security Testing

Verify:
- Authentication
- Authorization
- Validation
- File uploads
- API endpoints
- Rate limiting
- CSRF
- XSS
- SQL injection
- Credential exposure

## Browser Priority

1. Mobile Chrome/Safari
2. Desktop
3. Other supported browsers

## Definition of Done

A feature is complete only when:
- Function works
- Responsive behavior is valid
- Accessibility is checked
- SEO is valid where applicable
- Performance is acceptable
- Security is checked
- No critical regression exists
