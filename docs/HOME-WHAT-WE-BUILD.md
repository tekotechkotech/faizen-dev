# Homepage: What We Build

## Visual Ecosystem with Clear Type Labels

This section displays what Faizen has built, organized into three clear categories. The visual language is unified while allowing each type to expose its relevant information.

### Three Build Categories

#### 1. BUILD / Client Project

- Shows Faizen's client work, internal projects, and experiments
- Each project item: brief title, context/discipline, and visual thumbnail
- Layout: structured list or compact cards with consistent margin/padding (8-point foundation)
- No fake statistics (e.g., "100+ projects"), no generic jargon

#### 2. SOLUTION / Faizen Product

- Shows Faizen's own products and solutions
- Each solution: product name, brief description, primary use case
- Visual: product interface screenshot with muted, high-contrast styling
- Emerald accent used sparingly for callout or highlight text

#### 3. SERVICE

- Shows the service offerings Faizen provides
- Each service: title, short description, relevance to visitor
- Layout consistent with the 4-point/8-point spacing foundation

### Layout & Information Density

- **Desktop**: Three columns or a compact grid with clear separation between categories
- **Mobile**: Single column, stacked vertically, each category gets full width
- **Spacing**: Consistent with neutral 4-point/8-point foundation; tight grouping within categories, wider gutter between categories
- **No decorative whitespace**: whitespace clarifies hierarchy and density, not to fill space
- **High information density**: real project data and solution descriptions, not empty cards

### Type Label Visual Treatment

Each item clearly labels its category using the unified visual language:

- Category badge/label with emerald accent text on neutral background
- Consistent typography: headings in Geist Display / Cabinet Grotesk, body in Plus Jakarta Sans / Satoshi
- All headings use `font-style: normal` (roman)
- Maximum 2 fonts applied across the section
